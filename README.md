# PAUSE

A digital, Vestaboard-inspired split-flap display prototype for intentional screen-time awareness.

## V1
- Faithful 6 × 22 character layout, matte black frame, mechanical flip motion and optional click audio
- Compose and display custom messages
- Color flaps and curated demo scenes
- Fullscreen ambient mode; settings and messages persist locally in the browser

## Run
Open `index.html` in a browser, or serve the repository as a static site (Vercel / GitHub Pages). No build step or API keys required.

Screen-time figures in V1 presets are **illustrative**; no device monitoring or AI integration is claimed.

This is an independent concept prototype, not affiliated with Vestaboard.
