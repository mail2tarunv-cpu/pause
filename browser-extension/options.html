PAUSEEXTENSION PRIVACY

Your browsing stays yours.

PAUSE observes only the currently focused website in this browser, while you're active and have enabled tracking. It sends just the website's hostname, e.g. figma.com, to 127.0.0.1:8766 on your own Mac.

  • No full URLs, paths, queries, browsing history, page titles, search queries, cookies or page content are collected.
  • Nothing is sent to a remote server by this extension.
  • The Mac application counts foreground app time and merges browser observations to avoid double counting.
  • Tracking is off until you pair. Pause or forget the pairing at any time.
  • The 48-character token authenticates the local connection. Keep it private.

Install: Open the native PAUSE for Mac app, copy the Browser pairing code, click the PAUSE extension icon, paste the code, then Pair / Test. The Mac app must be running.

Safari requires a separate Safari Web Extension host app and is not included in this Chrome/Chromium package. Native Safari time is still tracked as an application by PAUSE for Mac.
